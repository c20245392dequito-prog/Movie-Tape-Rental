
# REELVAULT — Movie Tape Rental & Collectibles

## Author
Jive Miguel V. Dequito

## Business Concept
REELVAULT is a fictional small movie-tape rental and
collectibles shop based in Victorias City, Negros Occidental.

Address:
Zone 4, Tinapok Street,
Victorias City, Negros Occidental, Philippines.

## Technology Stack
- HTML5
- Tailwind CSS v4 CDN
- Vanilla JavaScript
- GSAP 3.13.0
- ScrollTrigger 3.13.0

## Design Style: Spatial UI
The website uses floating interface panels, translucent
surfaces, layered shadows, cinematic poster imagery,
depth, and responsive layouts.

## 60-30-10 Color Palette
- 60% Primary: #F3F5FF — Light background
- 30% Secondary: #DFE5FF — Supporting surfaces
- 10% Accent: #6244DD — Buttons and highlights

Supporting colors:
- Text: #1D2543
- Dark background: #0B1022
- Dark cards: #18213A

Color contrast should be verified using a WCAG
contrast checker before final submission.

## Main Features
- Responsive navigation
- Light and dark mode
- Movie poster catalog
- Search and genre filters
- Rent or purchase selections
- Rental duration selection
- Shopping cart and quantity controls
- Demo stock availability
- Checkout form
- Order receipt
- Recent demo orders
- Contact form
- GSAP introduction timeline
- Replay animation
- ScrollTrigger section reveals
- Scrubbed scroll progress bar
- Reduced-motion support

## Animation Requirements
The GSAP timeline uses defaults, stagger,
overlapping animations, and selected easing.

Section reveals use ScrollTrigger with start
and toggleActions.

The progress indicator uses scrub and ease: none.

## Accessibility
- Semantic HTML
- Labeled form fields
- Alt text for posters
- Keyboard-accessible buttons
- Responsive layouts
- Reduced-motion support

## Project Files
- index.html
- script.js
- README.md

## Important Limitations
This is a front-end demonstration only.

No real payments or reservations are processed.
Inventory and orders are stored locally in the browser.
Rental returns are not automatically tracked.

Movie posters are illustrative external images
loaded from TMDB image URLs. Poster usage and
licensing should be reviewed before public deployment.
